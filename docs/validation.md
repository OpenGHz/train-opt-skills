- 当前环境没有安装 PyTorch，未执行真实训练、CUDA profiler、多卡 DDP/FSDP、GPU 数值或任务成功率实验。
- 五个工具分别检查输入和约定，不自动证明训练等价、收敛质量、统计显著性或固定加速倍数。性能示例明确为合成数据。
- 未安装或执行第三方专项技能；已核对上游来源与内容，测试缺失、歧义、哈希和依赖元数据等发现状态。找到文件不等于能力已验证。
- CI 配置了 Python 3.10/3.12；实际本地执行为 3.12，未声称远端 GitHub Actions 已运行。
- 未启动第三方客户端安装或执行 npx 网络安装。离线复制及拒绝覆盖行为已测试；宿主发现与插件支持受客户端版本约束。
- 通用评测运行器需要用户提供可调用的 Agent 适配命令；不内置模型账号或 API 凭据。任务目录复制不是操作系统安全沙箱。
- 对照记录保留任务和技能快照哈希，没有完整模型调用轨迹或模型标识。最终专项发现加固晚于这组试验，试验不代表最终全部集成路径已由 Agent 实跑。
- 原始指南和调研保留历史来源链接；当前训练环境仍需按实际依赖版本核对。
