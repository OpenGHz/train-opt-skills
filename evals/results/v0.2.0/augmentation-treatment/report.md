# 归一化修复报告

## 结果

保留正确性修复。原实现跨批次合并像素计算统计量，违反逐图独立归一化约定。修复为按图计算总体均值与总体方差，分母为 `sqrt(variance + 1e-5)`。新增空图像 ValueError；空批次自然返回空列表。

## 契约与验证

CPU、Python 浮点算术、合成固定与可复现输入。参考使用独立的 `statistics.mean` / `statistics.pvariance`；运行前验证脚本中声明 `atol=rtol=1e-12`。批间独立性、形状和输入保护使用精确断言。

| 检查 | 修复前 | 修复后 |
| --- | --- | --- |
| 独立参考对齐 | 失败 | 通过 |
| 总体方差与 epsilon | 通过 | 通过 |
| 添加/替换/重排批内邻居和单图处理 | 失败 | 通过 |
| 不等长列表形状、输入不修改及输出不别名 | 通过 | 通过 |
| 空批次 | 失败 | 通过 |
| 空图像 ValueError | 失败 | 通过 |
| 常量与单像素图像 | 失败 | 通过 |

28 组输入、519 个像素，最大绝对误差 2.220446049250313e-16。实际输入、软件版本、源码哈希和逐项结果已写入验证 JSON。

## 复现与测量边界

- 修复前执行 `python validate_normalize.py --phase baseline`，退出码 1，证据 `baseline_validation.json`。
- 修复后执行 `python validate_normalize.py --phase candidate`，退出码 0，证据 `candidate_validation.json`。
- 回滚命令：`patch -R pipeline.py < repair.patch`。运行修复前检查应先回滚，避免覆盖原始证据。
- 变更记录：`repair.patch`；实验记录：`experiment.json`；任务结果：`response.json`。

旧实现是缺陷基线，不能用作等价性能基线。吞吐量、更新时延、完整训练耗时、峰值内存与任务质量均未测量。不声称加速。

## 限制

本结果仅证明这些 CPU 夹具的确定性逐图统计行为；未验证随机参数、抽样粒度或随机流，不能推出随机增强等价性。GPU、生产训练、损失/梯度/优化器更新和任务质量均未验证。如需训练接受证据，应使用真实输入及固定随机增强参数另做下游对齐与任务评估。
