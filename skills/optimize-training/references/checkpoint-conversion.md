# Checkpoint 转换、恢复与部署验收

在 JAX/PyTorch 迁移、模型格式变更、分片权重导出或部署打包时使用本页。
转换属于模型语义：同形状、严格加载成功都不能独立证明转换正确。

## 先声明产物用途

| 用途 | 最少要验证的内容 |
| --- | --- |
| 推理 | 配置、模型/必要 buffer、预后处理、最终输出与目标运行时 |
| 重新启动训练 | 以上内容加初始梯度/更新；声明哪些训练状态重新初始化 |
| 精确断点续训 | 模型、优化器、调度器、随机状态、训练已消费数据进度及继续训练对照 |

只有模型权重的导出不能自动称为精确续训产物。
精确恢复的含义应在约定硬件/软件/随机性范围内定义，不能跨环境无条件承诺逐位一致。
每条转换方向独立验收，不能用新到旧通过代替旧到新或训练到部署通过。

## 转换清单

固定源 checkpoint 哈希/标识、源目标格式版本、模型配置和转换器提交。
每个键记录源/目标名字、形状、轴含义、dtype、重排规则和允许例外。
将参数、必要 buffer、共享/绑定关系纳入同一清单。

| 部分 | 必查映射 |
| --- | --- |
| Linear / Conv | 输入输出轴、卷积布局、transpose/permute 的位置 |
| Q/K/V | 拼接顺序/轴、bias、head 和 group 维的还原 |
| 门控 FFN | gate/up 顺序、stack/concat 轴和 down projection 方向 |
| 包装器 | 仅清理确认存在的白名单前缀，检测重命名碰撞 |
| 分片/展平 | 按原保存协议恢复完整参数及状态，不能只删前缀 |
| 参数与 buffer | 最终实际 dtype、共享权重、归一化统计等必要状态 |

方阵转置和 Q/K/V 同形状置换可能完全通过键名/形状检查。
映射需要解释张量轴语义，不能由名字相似推断。
多专家或 head 配置变化需核对配置兼容性，不能将任意 reshape 当合法转换。

## 实施与加载

1. 验证源文件身份、配置和完整性；保存映射的可审查清单。
2. 依版本化规则转换，逐项验证目标键、形状、dtype 和共享关系。
3. 检查缺失、多余、重名及允许例外，异常默认停止该条转换。
4. 在最终目标模型执行 `load_state_dict(..., strict=True)`。
5. 加载后检查实际张量与必要状态，不能只检查转换前字典。
6. 固定输入比较关键中间值和最终输出，并保存误差记录。
7. 按产物用途继续执行更新/恢复或实际部署管线测试。

不要通过随意 `strict=False`、忽略键或零填充未知参数使转换“成功”。
有意丢弃字段必须预先列出原因，再对最终目标模型严格加载。
兼容字段只能来自身份明确、配置匹配且用途核实的参考状态。
不得从任意同名模型补齐训练参数；无法确认来源时报告缺项并停止转换。

## 数值回归与往返测试

保存固定原始输入、最终输入、mask、位置索引和随机输入，复用同一初始状态。
先比较输入投影/视觉 stem，再逐块、输出头、损失，定位首个超容差边界。
检查非有限值、最大误差和分布；阈值按模型精度和敏感性提前定义。
用于继续训练时比较对应梯度、裁剪、一次更新后参数及优化器状态。
纯可逆重排可做往返测试，验证恢复原张量。
降低精度、删除字段或单向格式存在不可逆部分，需显式声明，不宣称无损往返。
往返成功仍不替代最终目标模型的输出测试：双方相反的同类错误可能互相抵消。

## 断点续训

从同一状态分别运行不中断分支和保存—恢复分支，比较后续输入及更新结果。
核对优化器参数组、动量状态、调度器计数、梯度累积边界和随机状态。
记录训练已经消费的数据，而非仅记录读取端或预取端游标。
考虑 worker 预取领先、epoch 打乱、尾批和拓扑变化，声明允许的重放/跳过策略。
分布式保存及恢复必须按实际并行实现协议测试，单卡加载不证明多卡恢复正确。
若缺少原始优化器或数据进度，只能声明重新训练/近似恢复，不能补成精确续训。

## 实际部署验证

部署端从原始样本进入完整预处理、模型和后处理，而非只调用转换脚本内的 forward。
VLA/策略检查相机顺序、tokenizer、状态/动作归一化及动作后处理。
比较目标运行时中的实际 dtype、必要配置和输出布局。
使用代表性正常与边界输入，并按项目质量门槛评估真实任务行为。
导出权重、配置、归一化统计和必要兼容信息作为一致产物交付。

## 交付清单与决策

保留源标识/哈希、源目标配置、转换器提交、映射/例外、目标 dtype 和验证记录。
明确产物用途和不能支持的恢复承诺，记录未运行的目标硬件测试。
键/形状失败先修映射；数值失败定位模块；端到端失败检查预后处理与运行时。
质量或用途验收未通过时保留转换产物为待验证状态，不替换已验证产物。
所有性能结论与转换正确性结论分开，加载速度不能证明模型可用。
