# 基线、性能剖析与收益归因

在训练慢、GPU 利用率异常或需要验证加速结论时使用本页。
优先产出可信测量，再决定优化方向；GPU 利用率本身不是有效工作量。

## 固定对照条件

记录代码提交、依赖锁文件、启动命令、硬件拓扑、CPU 配额和存储位置。
固定模型/权重、数据版本、采样/增强、精度、损失、优化器和评估/保存频率。
微批、数据并行副本数、累积次数、尾批规则均需明确。
普通等长数据并行中，全局批大小为三者乘积；混合并行的副本数不等于总 GPU 数。
变长 token、尾批和按权重归一化时，按实际参与更新的工作量核算。
增加微批并减少累积后，即使乘积不变，也要检查批次相关层、随机过程和损失缩放。

## 指标与边界

| 指标 | 口径 |
| --- | --- |
| 有效吞吐 | 测量窗口内完成的有效样本或非 padding token / 实际秒数 |
| 更新耗时 | 完成一次 optimizer 更新，包含全部累积微步 |
| 波动 | 更新耗时中位数、P95；保留各轮原始统计 |
| 显存 | 每卡峰值 allocated、reserved，另记设备级占用 |
| 暴露等待 | 数据、拷贝或通信实际推迟关键路径的时间 |
| 作业耗时 | 启动、编译、训练、评估、保存及必要准备的总墙钟时间 |
| 质量 | 预先约定的验证或策略任务指标及其不确定性 |

不同长度分布的 samples/s 不直接可比；记录有效 token 或其他业务工作量。
实际处理条目数、唯一样本 ID 和非预期重复数用于数据审计，应分开报告。
唯一 ID 不等于统计独立样本；有意重复采样不应自动从吞吐分母剔除。

## 定位模式：短窗口保留时间线

用 profiler 阶段标记覆盖取数/解码、H2D/预处理、前向、损失、反向/通信、更新。
另记启动/编译、日志、评估、保存、数据切换和恢复。
采集有代表性的短窗口，必要时查看不同 rank，避免详细 profiler 扰动整个作业。
将“通信量大”“调用过碎”“调度过晚”“rank 负载不齐”分成不同假设。
等待慢 rank 可能源于取数或输入长度，而不是网络本身。

## 验收模式：关闭详细 profiler

1. 覆盖常见形状、worker 启动和编译缓存进行预热。
2. 开始前等待旧设备工作完成；多卡对齐测量起点。
3. 在连续窗口内保持正常流水和已约定的日志/保存策略。
4. 窗口结束等待相关设备工作完成，再读取墙钟耗时。
5. 窗口外汇总各 rank 完成量和耗时，使用覆盖最慢 rank 的一致口径。
6. 重复测量并保留原始结果；对噪声级收益采用交替 A/B。

CPU 计时若不处理异步完成，可能只量到工作提交。
设备事件只能覆盖其依赖链；单流事件不能替代完整多流、多卡墙钟。
不要逐算子全局同步做阶段计时，这会破坏原本的重叠。
若干十步预热、数百步测量、至少三轮可作起点，按实际稳定性调整，不能当硬性合格线。
真实保存/评估尖峰要单列解释，不能为了平滑曲线随意删除。

## 关键路径与重叠

| 概念 | 含义 |
| --- | --- |
| 通信活动时间 | 时间线上通信区间的并集 |
| 与计算重叠 | 通信活动和约定计算区间的交集 |
| 暴露通信等待 | 通信未完成而实际推迟后续必要工作 |

算子、拷贝、通信可并行，不能把活动时长直接相加得到更新耗时。
描述性重叠率也不自动等于被隐藏的真实成本；结论最终回到端到端时间。

## 实验选择与累计收益

每个实验写清：基线证据、瓶颈假设、最小改动、语义风险、通过标准、回滚方式。
优先单变量；有明确依赖时使用小组合并标出依赖，不强行测试无效配置。
最小序列为 B0、B0+A、B0+A+B；只有 B 可独立合法运行时才补 B0+B。
区分直接加速、降低资源占用和为后续优化创造条件三种价值。

同等有效工作量下，总加速比为基线耗时/最终耗时，或最终吞吐/基线吞吐。
不得相加不同基线上的百分比，或相乘独立实验的加速比预测组合结果。
连续实测阶段的相邻比值可代数连乘，但不能据此宣称优化彼此独立。
仅对完全串行且未重叠的阶段，使用 `1 / ((1-p)+p/s)` 估计局部优化的收益上限。

## 扩展性、成本与停止

强扩展固定总工作量；弱扩展固定每资源工作量，同时增加总工作量。
统一吞吐口径下，效率为 `Q(N) / ((N/N0) * Q(N0))`，披露输入与训练协议变化。
弱扩展可能增大全局批大小；吞吐提高不等于达到同等质量更快。
同时比较完整完成时间、总 GPU 小时、失败重试及存储/网络约束。
目标达到、收益落入噪声、维护成本大于价值或无法验证时停止并记录限制。

交付环境/配置、原始测量、代表性 trace、质量门槛、A/B 结论和保留/回滚决定。
没有真实 GPU/多卡结果时，只提供待执行方案和可验证的静态结论。
