# Project artwork

`train-opt-logo.png` is the README mark: an iteration loop and verification check,
with teal and amber accents. The PNG has a transparent background and is shared
by both language versions. The existing installable skill icon is separate.

`badges/` contains self-contained SVG labels for Agent Skill, Python 3.10+, and
the project license. They are static metadata, not live CI status indicators.

The project logo was created on 2026-10-05 with the built-in image generation
tool, with `transparent_background=true`; no reference image was supplied.
The selected output is retained unchanged. Project artwork is covered by the
root project license.
